# Data WareHouse and Analytic Project
This project contains the design,implementation and deployment resources for SQL Server based Data Warehouse.
It includes the data model, ETL processes, schemas,stored procedures and documentation
 needed to support analytics and reporting.
 ----
 # Project Requirement
 
 ## Building the Data Warehouse

### BI: Analytics and Reporting
 
#### Specifications
 **Data Source**: Import Data from two source system( ERP and CRM) provided as CSV files
 **Data Quality**: Cleanse and resolve data quality issues prior to analysis.
 **Integration**: Combine both sources into single, user-friendly data model designed for analytic queries.
 **Scope**:Focus on the latest dataset only : historization of data is not required.
 **Documentation**: Provide clear documentation of the data model to support both business stakeholders analytic teams.
 
 #### Objective of the Project
To design  and implement a scalable SQL SERVER-based Data Warehouse that consolidates data from two source system, ensures data quality and provides an optimized foundation for analytics and reporting.

This insights provides standardized metrics and KPIs across organization, enables faster, data-driven decisions by giving stakeholders access to clean, well organized data.
